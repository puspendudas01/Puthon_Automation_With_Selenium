# Selenium Video Assessments (4 assignments)

Local practice page: `demo_page.html` (no internet needed).

| Script | Topic |
|--------|-------|
| assignment1.py | By.ID, NAME, TAG_NAME, LINK_TEXT, CLASS_NAME |
| assignment2.py | find_elements: list of links |
| assignment3.py | CSS wildcard selectors (^=, *=, $=) |
| assignment4.py | CSS child selector (#profile-card > button) |

## Run
```
pip install selenium
python assignment1.py
python assignment2.py
python assignment3.py
python assignment4.py
```
Google Chrome must be installed. Screenshots are saved to `screenshots/`.
Change the pause between steps with `PAUSE` in `common.py`.
